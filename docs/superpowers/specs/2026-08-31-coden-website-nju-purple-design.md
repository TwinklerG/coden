# CodeN 网站南大紫视觉统一设计

## 背景

CodeN 文档站已经形成克制、清晰的极客视觉语言：低饱和背景、细网格、等宽标题、小圆角边框、透明面板和有限的强调色。产品首页、插件市场、语言入口页与 404 页面仍大量使用胶囊按钮、大圆角、阴影和柔和渐变，导致产品站与文档站风格割裂。

本次改造将全站配色统一为南京大学“南大紫”风格，并让所有非文档页面复用文档站的视觉原则。内容结构、页面功能和交互行为保持不变。

## 目标

- 将文档站的蓝绿色主题替换为南大紫主题。
- 统一首页、插件市场、语言入口页、404、Header 和 Footer 的视觉语言。
- 同时支持浅色与深色主题，并保持足够的文字和交互对比度。
- 保留现有响应式布局、键盘焦点、主题切换、复制命令和插件搜索功能。
- 避免组件重构和内容改写，将变更集中在样式层。

## 非目标

- 不改变页面信息架构、文案或路由。
- 不新增动画、图片、字体、外部样式依赖或 JavaScript 交互。
- 不修改 Starlight 的组件结构。
- 不改动根目录中与本任务无关的依赖文件，也不覆盖工作区中已有的 `SiteFooter.astro` 修改。

## 视觉方向

### 配色

南大紫作为唯一主强调色。深色主题采用近黑紫背景、明亮紫色强调和偏冷的浅灰紫文字；浅色主题采用近白紫背景、较深的南大紫强调和深紫灰文字。

强调色只用于当前导航、主要按钮、焦点、链接、编号和关键状态。普通面板依靠背景层级与细边框区分，避免大面积高饱和紫色。

### 形态

- 全站使用 2–3px 小圆角，不再使用胶囊按钮和大圆角卡片。
- 移除装饰性阴影，使用细边框与轻微背景差异建立层级。
- 页面背景使用与 docs 一致的 32px 低对比度网格。
- 标题、导航、标签、按钮和命令区域优先使用等宽字体。
- 保留现有留白和响应式断点，避免因纯视觉改造引入布局回归。

### 交互

- Hover 通过紫色边框、轻微紫色底色和文字颜色变化反馈，不使用位移或阴影。
- Focus-visible 使用清晰的紫色轮廓，满足键盘导航需求。
- 主要按钮使用实色南大紫；次要按钮保持透明或低对比度面板背景。
- 深浅主题共享同一语义变量，避免组件内硬编码两套颜色。

## 样式架构

### `website/src/styles/docs.css`

仅调整 Starlight 语义变量与网格颜色，把现有蓝绿色映射为南大紫。保留已经成功的排版、边框、侧栏、标题和提示框规则。

### `website/src/styles/global.css`

作为产品站统一设计令牌和壳层样式：

- 定义南大紫明暗主题变量。
- 将全局半径收敛为小圆角并移除阴影。
- 为产品页面加入 docs 风格网格背景。
- 统一 Header、Footer、导航、主题按钮、语言入口、404 和通用容器。
- 使用等宽字体强化品牌与技术产品气质。

### `website/src/styles/home.css`

保留 Hero、安装命令、CLI/TUI 演示、功能列表、快速开始和 CTA 的现有 DOM 与网格结构。所有区域改为细边框终端面板风格，删除装饰性柔和渐变、胶囊按钮和悬浮卡片效果。通过紫色左边线、标签、活动 Tab 和终端光标建立层级。

### `website/src/styles/plugins.css`

将搜索框、插件卡、元数据、安装命令和操作按钮统一为紧凑的技术面板。插件卡主要依靠边框和低对比背景分隔；命令区域使用等宽字体；状态和交互使用南大紫强调。

## 响应式与可访问性

- 保留现有 900px 响应式断点和单列降级行为。
- 交互元素继续满足至少 44px 的触控高度，但外观不再采用胶囊形。
- 保留 reduced-motion 规则。
- 明暗主题中的正文、弱化文字、边框和强调色应维持可辨识对比度。
- 不依赖颜色作为唯一状态信号；当前页面仍由边框、背景和字重共同表达。

## 验证

- 运行 `just website-check`，覆盖 Biome、Astro diagnostics、构建、Pagefind 和 built-site validator。
- 运行 `git diff --check` 检查空白错误。
- 确认构建产物仍包含产品站和文档站 CSS marker。
- 检查工作区差异，确保没有覆盖 `package.json`、`bun.lock` 和已有的 `SiteFooter.astro` 修改。

## 验收标准

1. 文档站的蓝绿色全部替换为协调的南大紫主题，原有布局和视觉规则不变。
2. 首页、插件市场、语言入口页、404、Header 和 Footer 与文档站呈现统一的网格、等宽、小圆角、细边框、无阴影风格。
3. 产品站不再出现大圆角卡片、胶囊按钮或装饰性阴影。
4. 浅色与深色主题均可正常阅读和操作。
5. 页面功能、响应式布局、搜索、复制命令和主题切换无回归。
6. 网站完整检查通过，且无无关文件被修改。
