# CodeN Full-Screen TUI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make an Ink 7 full-screen TUI the default interactive CodeN interface while preserving the existing CLI, print mode, runtime behavior, and non-TTY fallback.

**Architecture:** Extract the existing agent bootstrap and REPL command execution into UI-neutral services. Keep `AgentRuntime` and `EventBus` unchanged; the CLI continues to use `TerminalRenderer` and `MultilineEditor`, while an external `TuiStore` reduces the same events into transcript/activity/status state consumed by five Ink components and a thin controller.

**Tech Stack:** TypeScript, React 19, Ink 7, wrap-ansi, ink-use-mouse, Bun build tooling, Node.js 22+, Vitest, Biome

**Spec:** `docs/superpowers/specs/2026-08-30-coden-tui-design.md`

## Global Constraints

- Ink is isolated under `src/tui/`; `src/core/`, providers, tools, permissions, sessions, plugins, and context must not import React or Ink.
- Node.js 22 is the minimum published runtime; development still uses Bun without Bun-only runtime APIs.
- TUI is the default only when stdin and the selected output are interactive, raw mode exists, and `TERM !== "dumb"`.
- `--tui` explicitly requests TUI but warns and falls back when terminal capabilities are unavailable; `--cli` keeps the previous interface; `--print` remains non-interactive.
- `--tui` conflicts with `--cli` and `--print`; `--cli --print` remains valid.
- Keep one foreground turn. Running input is read-only; `Ctrl+C` cancels; no queue, sidebars, diff viewer, background tasks, or plugin UI.
- The TUI has exactly five CodeN components: transcript, input, activity, status, and permission/confirmation dialog.
- Reuse current editor semantics, terminal sanitization/width helpers, Markdown renderer, tool summaries, i18n, slash commands, session recovery, approval policy, and JSONL trace.
- Use Ink for full-screen rendering, wrap-ansi for line projection, and an Ink-compatible mouse hook; do not implement a second terminal renderer, mouse protocol, or general-purpose widget library.
- `--resume` without a session ID remains a non-interactive session-list operation and exits without starting TUI or requiring a provider key.
- Follow TDD for each behavior and preserve every existing test.
