## package.json 要求

```json
{
  "name": "@scope/coden-plugin-example",
  "version": "1.0.0",
  "type": "module",
  "files": ["dist"],
  "coden": {
    "apiVersion": 1,
    "plugin": "./dist/index.js"
  }
}
```

| 字段 | 要求 |
| --- | --- |
| `type` | 必须是 `"module"` |
| `coden.apiVersion` | 必须是 `1` |
| `coden.plugin` | 以 `./` 开头的 `.js` 或 `.mjs` 路径；不得含 `..`、`\`、`://` 或空白 |
| 入口文件 | 必须发布**构建后**的 JS；只发布 TypeScript 源码会被拒绝 |
| 入口边界 | 解析后的真实路径必须位于包目录内 |

## 导出形态（二选一）

单工具：默认导出 `ToolDefinition`：

```ts
import type { ToolDefinition } from "@twinklerg/coden/plugin";

const tool: ToolDefinition = {
  name: "example_echo",
  description: "Echo supplied text",
  risk: "read",
  inputSchema: {
    type: "object",
    additionalProperties: false,
    required: ["text"],
    properties: { text: { type: "string" } },
  },
  async execute(input) {
    const { text } = input as { text: string };
    return { content: text };
  },
};

export default tool;
```

多工具：默认导出 `CodeNPlugin`，其中 `name` 必须等于 npm 包名：

```ts
import type { CodeNPlugin, ToolDefinition } from "@twinklerg/coden/plugin";

const readTool: ToolDefinition = {
  name: "example_read",
  description: "Read example data",
  risk: "read",
  inputSchema: { type: "object", additionalProperties: false },
  async execute() {
    return { content: "read" };
  },
};

const plugin: CodeNPlugin = {
  apiVersion: 1,
  name: "@scope/coden-plugin-example",
  tools: [readTool],
};

export default plugin;
```

## 校验规则

| 检查 | 失败时的错误 |
| --- | --- |
| 导出不是工具或插件对象 | `plugin.export_invalid` |
| `apiVersion` 不是 1 | `plugin.api_unsupported` |
| `CodeNPlugin.name` 与包名不一致 | `plugin.name_mismatch` |
| `tools` 为空或含非法工具 | `plugin.export_invalid` |
| 工具名不匹配 `^[a-zA-Z][a-zA-Z0-9_-]{0,63}$` | `tool.invalid_name` |
| 与已有工具重名 | `tool.duplicate`（本地加载）/ `plugin.tool_conflict`（npm 组合） |
| inputSchema 非法 | `tool.invalid_schema` |

## 公共契约

- `@twinklerg/coden/plugin` 是唯一公开子路径；主入口 `"."` 未公开，`import "@twinklerg/coden"` 会被拒绝。
- `ToolDefinition`/`CodeNPlugin` 类型从该子路径导入；把 `@twinklerg/coden` 放入 `devDependencies`，`import type` 在构建时移除，运行时不会加载另一份 CodeN。
- `ToolContext.signal` 是 `AbortSignal`：tsconfig 需提供相应 lib（如 `@types/node` 或 DOM）。
- 契约以仓库 `src/plugin/index.ts` 为唯一来源；构建自动生成 `dist/plugin/index.js` 与 `dist/plugin/index.d.ts`，不发布 `src`。
