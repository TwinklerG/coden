## 启动与配置

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| `CODEN_OPENAI_API_KEY is required` | 未设置 Key（默认 Provider） | `export CODEN_OPENAI_API_KEY=...` 或配置 `env` 字段 |
| `CODEN_ANTHROPIC_API_KEY is required` | `--provider anthropic` 但未设置 Key | 导出 `CODEN_ANTHROPIC_API_KEY` |
| `Cannot read config ...` | 配置文件 JSON 无效 | 修复对应作用域的 `config.json` |
| `language must be zh or en` | 配置/`--lang` 非法值 | 使用 `zh`/`en`；检查用户配置 |
| `--tui and --cli are mutually exclusive` | 界面参数冲突 | 只保留一个界面选项 |
| `--smart-approve and --auto are mutually exclusive` | 审批参数冲突 | 二选一 |
| `--allow-outside-workspace requires --auto` | 单独使用该选项 | 与 `--auto` 组合 |
| `print mode requires a prompt` | `-p` 未提供任务 | 添加 prompt 参数 |
| `Anthropic enabled thinking requires maxOutputTokens greater than 1024` | `reservedOutputTokens <= 1024` 且启用思考 | 增大 `reservedOutputTokens` 或降低思考等级 |

## 运行期

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| `runtime.step_limit`（`Maximum model steps (20) reached`） | 超过 `maxSteps` | 拆分任务或提高 `--max-steps` |
| `context.exhausted` | 紧急压缩后仍超预算 | 用 `/new` 或新会话，减小单次任务范围 |
| `permission.denied` | 权限被拒 | 换用更安全的操作或人工放行 |
| `permission.outside_workspace_denied` | `--auto` 下访问工作区外 | 确有必要时使用 `--auto --allow-outside-workspace` |
| `tool.timeout` | 工具未在 60 秒内完成（且未协作取消） | 缩短命令/工具逻辑；检查插件协作取消 |
| `edit.no_match` / `edit.multiple_matches` | `oldText` 未找到或不唯一 | 精确复制待替换文本 |

## 插件

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| `plugin.specifier_invalid` | specifier 不合法 | 使用 `npm:<package>` 或 `npm:<package>@<version-or-tag>` |
| `plugin.install_busy` | 同作用域事务锁被占用 | 稍后重试（过期锁自动清理） |
| `plugin.lock_missing` | 项目 `sync` 缺 `bun.lock` | 先 `plugin install` 或提交锁文件 |
| `plugin.lock_outdated` | 锁文件与清单不一致 | 更新锁文件并提交 |
| `plugin.manifest_invalid` | `plugins.json` 损坏 | 修复清单；必要时删除并重新安装 |
| `plugin.metadata_missing` / `plugin.entry_invalid` / `plugin.api_unsupported` / `plugin.name_mismatch` | 包不符合作者协议 | 对照[插件作者协议](../plugins/author-protocol)修正包 |
| 插件加载失败、工具未注册 | 顶层代码/入口异常；Node 运行时加载 `.ts` 插件失败 | 查看 `coden plugin list`；用 Bun 运行或改用 npm 插件 |
| `plugin restart required` | 运行中 npm 插件元数据变化 | 重启 CodeN |

## Hook

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 配置解析失败：`unsupported hook event`/`invalid matcher`/`timeout` 范围 | Hook 配置非法 | 对照 [匹配规则](../hooks/matchers) 与 [执行与超时](../hooks/execution) |
| `X config exceeds 64 commands` | 单事件 Hook 超限 | 精简 Hook |
| Hook 静默失效 | 非零退出、超时、输出超限、非法 JSON | `--verbose` 查看；检查脚本 stdin/stdout 协议 |

## Skill 与运行时

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| Skill 未生效 | 目录名/frontmatter 不一致或文件非法 | `--verbose` 查看 `ignored ...` 原因；重启 |
| 本地 `.ts` 插件在 Node 下不加载 | Node 不支持 `data:text/typescript` | 用 Bun 运行（或使用 npm 插件） |
