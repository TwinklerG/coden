CodeN 是一个有意思的 Coding Agent，以可插拔工具插件为特色。它保持核心执行路径小而透明：模型看到工具协议，决定何时调用工具，CodeN 负责校验、授权、执行、记录并把结果送回下一次模型请求。这里的“有意思”不是人格包装，而是你可以观察并重塑这条路径。

这套文档面向希望理解 Agent 而不只使用命令的读者。先建立运行循环与安全边界，再选择 Plugin、Skill、Hook 或项目指令扩展系统；需要精确字段时再进入协议参考。所有行为均以当前源码、测试和发布产物为准。

CodeN（Code NJU）是一个以可插拔工具插件为特色的 Coding Agent。它直接使用模型原生 Tool Calling，在本地读取、修改文件和执行命令；核心小而透明，不依赖 Agent 框架或服务端代码执行。

## 最短上手路径

```bash
bun add -g @twinklerg/coden      # or npm install -g @twinklerg/coden
export CODEN_OPENAI_API_KEY=...  # or CODEN_ANTHROPIC_API_KEY
coden "fix the failing tests in this project"
```

三条命令即可完成安装、配置和首个任务。启动后默认进入 CLI/REPL，工作目录即工作区。

## 行为边界

- 每条命令、配置键和行为均以当前版本源码为唯一事实来源。
- CodeN 不读取系统区域设置，默认界面语言为中文。
- `bash` 与插件以当前用户进程权限运行，这不是通用安全沙箱；风险分类是防误操作的启发式护栏。
- 会话与 trace 保存在本地数据目录，可能包含敏感内容，请勿未经审查地分享。
