## 启动与降级

```bash
coden --tui "your task"
coden --tui
```

`--tui` 要求 stdin/stdout 均为 TTY、支持 raw mode 且 `TERM != dumb`。任一条件不满足时降级为 CLI 并显示警告（不报错）；TUI 初始化异常同样降级。`--tui` 不能与 `--cli` 或 `--print` 同时出现。

## 界面布局

- 内容区保持 CLI 风格：瞬时思考、工具活动进入 transcript 流，跟随当前对话位置。
- 输入区由上下两条贯穿全宽的水平线包围；下方依次显示 provider/model、工作区、授权模式、阶段、上下文占用状态。
- 等待交互（授权、信任、插件确认）时输入区可见但禁用，请求内联显示在 transcript 中，不弹窗。
- 请求、可用选项与最终选择永久保留在当前 transcript。

## 快捷键

| 按键 | 行为 |
| --- | --- |
| `Enter` | 提交输入 |
| `Shift+Enter` / 行尾 `\` | 插入换行 |
| `Ctrl+P` / `Ctrl+N` | 浏览输入历史 |
| `PageUp` / `PageDown`、滚轮 | 浏览 transcript |
| `End` | 回到最新内容 |
| 运行中 `Ctrl+C` | 取消当前任务 |
| 空闲时 `Ctrl+C` | 触发退出流程（确认后退出） |
| 空输入 `Ctrl+D` | 退出 |
| `Esc` | 拒绝当前内联授权请求 |

## 执行模型

- 单任务串行：运行中不排队输入，提交后输入保持禁用直至完成或取消。
- 相同的斜杠命令集合可用（`/help`、`/skills`、`/session`、`/sessions`、`/compact`、`/reload`、`/new`、`/lang`、`/thinking`、`/quit`）。
- 通过 Kitty 键盘协议做转义序列消歧；`Ctrl+C` 不直接终止进程（自定义处理）。
