## 选项总表

| 选项 | 默认 | 说明 |
| --- | --- | --- |
| `<prompt>` | — | 要执行的任务；省略时进入 REPL |
| `-p, --print` | `false` | 非交互输出模式；需提供 prompt；单轮后退出 |
| `--tui` | `false` | 显式启动全屏 TUI；不满足 TTY/raw mode/`TERM` 条件时降级 CLI 并警告 |
| `--cli` | `false` | 显式使用 CLI 界面（默认模式） |
| `--provider <openai\|anthropic>` | `openai` | 模型 Provider |
| `--model <model-id>` | `gpt-5-mini` | 模型标识符 |
| `--resume [session-id]` | — | 带 ID 恢复会话；省略 ID 列出当前工作区会话 |
| `--auto` | `false` | 跳过工具权限确认（仅工作区内普通操作） |
| `--smart-approve` | `false` | 普通修改由 LLM 审查，不确定转人工 |
| `--allow-outside-workspace` | `false` | 与 `--auto` 一起允许工作区外读写路径 |
| `--verbose` | `false` | 显示详细运行状态 |
| `--max-steps <n>` | `20` | 最大模型步骤数（正整数） |
| `--thinking <level>` | 配置值/`default` | 思考等级：`default`/`off`/`minimal`/`low`/`medium`/`high` |
| `--plugin <path>` | `[]` | 附加本地 TypeScript 插件或目录，可重复 |
| `--lang <zh\|en>` | 配置值/`zh` | 界面与 Agent 语言，仅覆盖当前进程 |
| `-V, --version` | — | 输出版本（0.1.9） |
| `-h, --help` | — | 输出帮助 |

## 校验与互斥

- `--tui` 与 `--cli`、`--tui` 与 `--print` 互斥，同时传入报参数错误；`--cli` 与 `--print` 可共存且 `print` 优先。
- `--smart-approve` 与 `--auto` 互斥（配置错误，退出码 2）。
- `--allow-outside-workspace` 必须与 `--auto` 同时使用。
- `--provider` 仅接受 `openai`/`anthropic`；`--max-steps` 必须为正整数；`--thinking` 仅接受六档等级。
- `--resume` 与 `--auto` 等审批选项可组合（恢复后沿用当前命令行设置）。
- 无效环境变量（如 `CODEN_THINKING_LEVEL=bad`）在配置加载阶段报错，退出码 2。

## 参数优先级

CLI 参数 > `CODEN_*` 环境变量 > 项目配置 > 用户配置 > 默认值（`--lang` 例外：仅用户配置路径 + `--lang` 覆盖）。
