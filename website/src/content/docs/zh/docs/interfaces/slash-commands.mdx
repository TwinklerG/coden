## 命令列表

| 命令 | 行为 |
| --- | --- |
| `/help` | 列出全部命令 |
| `/skills` | 列出当前生效的 Skill（名称、描述、project/user 来源），不调用模型 |
| `/session` | 输出当前会话 ID |
| `/sessions` | 列出当前工作区的全部会话（按最后活动倒序） |
| `/compact` | 立即压缩上下文（手动触发自动压缩流程，结果持久化） |
| `/reload` | 重新加载本地 TypeScript 插件与 npm 插件注册表，输出加载/失败/工具摘要 |
| `/new` | 在当前会话内开始新对话（保留 system 消息，清除摘要与历史） |
| `/lang` | 列出 `zh`、`en` 与当前语言 |
| `/lang <zh\|en>` | 切换语言；以 `0600` 原子写入用户配置并立即生效 |
| `/thinking` | 列出思考等级、当前值与有效映射 |
| `/thinking <level>` | 切换等级并持久化到当前会话 |
| `/quit` | 退出 |

## 解析规则

- 命令必须独占一行：包含换行的输入（如 `多行输入\n/help`）按普通消息处理。
- 严格匹配命令名：`/help` 前导/尾随空白会被 trim 后识别；未知前缀按普通任务提交。
- 无效参数不会终止会话：`/lang xx`、`/thinking xx` 输出错误与可用列表，继续交互。

## 副作用说明

- `/lang` 只接受 `zh`/`en`；写入的是**用户级**配置文件，保留其他字段。
- `/thinking` 只影响当前进程与当前会话，不写用户/项目配置文件。
- `/reload` 只保证重新读取本地 `.ts` 插件（npm 包变更需要重启 CodeN）。
- `/new` 不改变思考等级；会话授权集合（`s` 授权）绑定当前进程，不会因 `/new` 清除。
