## 触发与约束

```bash
coden -p "Reply with exactly: coden-ok"
coden -p --auto "run the tests and report the results"
```

- `-p/--print` 必须携带 prompt：print 模式下无 prompt 会直接报错（`print mode requires a prompt`）。
- 单轮运行后退出：适合脚本、CI 与管道。
- 输出为纯文本流；`--auto` 配合跳过工作区内工具确认。
- 与 `--tui` 互斥；与 `--cli` 同时出现时 `print` 优先（不报错）。

## 与非交互环境的组合

| 场景 | 命令 |
| --- | --- |
| 单轮输出 | `coden -p --auto "your task"` |
| 指定 Provider 与模型 | `coden -p --provider anthropic --model claude-sonnet-4-20250514 "your task"` |
| 恢复会话后继续 | `coden -p --auto --resume <session-id> "continue"` |
| 英文界面 | `coden -p --lang en "your task"` |

## 注意

- print 模式不改变权限语义：工作区外 `read`/`write`/`edit` 在 `--auto` 下仍返回 `permission.outside_workspace_denied`。
- 非 TTY 环境不隐式启用 print；界面模式只由参数决定。
- 退出码：配置错误为 `2`，执行失败为 `1`，正常完成为 `0`。
