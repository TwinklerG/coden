工具决定 Agent 的行动空间，上下文决定模型能基于什么状态作出下一步选择。工具描述和 JSON Schema 会进入模型请求；工具结果则成为消息历史。权限、风险和路径检查发生在本地执行侧，不应被误解为模型自身的安全能力。

## 工具与风险等级

### 内置工具

| 工具 | 风险 | 输入要点 | 关键行为 |
| --- | --- | --- | --- |
| `read` | `read` | `path`、`offset`（默认 1）、`limit`（默认 500，上限 2000） | 按 1 起始行偏移读 UTF-8 文本；输出上限 50000 字符，超出提示省略；`O_NOFOLLOW` 打开 |
| `write` | `modify` | `path`、`content` | 创建或完整覆盖；文件模式 `0600`；自动创建父目录 |
| `edit` | `modify` | `path`、`oldText`、`newText` | 精确替换**唯一**匹配块；不唯一返回 `edit.multiple_matches`，未找到返回 `edit.no_match` |
| `bash` | `modify`（命令可升级为 `dangerous`） | `command`、`timeout`（默认 30000，范围 100–60000）、`maxOutput`（默认 30000，范围 1000–100000） | `bash -lc` 以工作区为 cwd；非零退出码、超时或取消都标记错误；超时终止进程组 |
| `activate_skill` | `read` | `name` | 按名称加载 Skill 的完整说明与根目录；无效名称返回 `skill.not_found`；仅读取已发现的入口文件并校验内容未变 |

工具按模型返回的 tool_calls 顺序执行；单次调用超时 60 秒（超时需要工具配合取消）。所有工具输出在回填上下文前截断到 50000 字符。

### 风险等级与授权

| 等级 | 默认交互模式 | `--smart-approve` | `--auto` |
| --- | --- | --- | --- |
| `read` | 自动允许 | 自动允许 | 自动允许 |
| `modify` | 人工确认（`y`/`s`/`N`） | LLM 审查，不确定转人工 | 自动允许 |
| `dangerous` | 人工确认（仅 `y`/`N`，无会话授权） | 人工确认 | 自动允许（Hook 的 `deny` 仍生效） |

### 危险命令识别（bash）

以下命令片段会导致 `bash` 风险升级为 `dangerous`：

```text
rm -r / rm --recursive
sudo
git reset --hard
git clean -f
git push --force / --force-with-lease
git checkout -- <path>
git restore
mkfs / fdisk / dd
killall / pkill
curl|sh or wget|sh
path contains /etc /usr /bin /sbin
```

风险分类是防误操作的启发式护栏，不是安全沙箱：`bash` 与插件拥有当前用户进程权限。

### 插件工具

- 本地或 npm 插件注册的工具使用各自声明的 `risk` 字段，参与相同的授权流程。
- 工具名须匹配 `^[a-zA-Z][a-zA-Z0-9_-]{0,63}$`；重名（含与内置工具冲突）导致该插件整体跳过。
- 插件工具执行受同样的 60 秒超时与 `AbortSignal` 协作取消约束。

## 上下文与思考等级

### 上下文预算

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| `contextWindow` | `128000` | Provider 上下文窗口 |
| `reservedOutputTokens` | `8192` | 每次请求的 `maxOutputTokens` |
| `safetyMargin` | `4096` | 输入预算的安全余量 |
| 输入预算 | `115712` | `contextWindow − reservedOutputTokens − safetyMargin` |

校验规则：三者必须是非负整数；`contextWindow` 与 `reservedOutputTokens` 必须为正；`contextWindow` 必须大于 `reservedOutputTokens + safetyMargin`。估算方法：文本按 `length / 3.5` 向上取整，每条消息额外计 6，工具定义按 JSON 估算——这是估算器，不是 Provider 精确计费。

### 自动压缩

- 当预估输入超过输入预算的 **80%** 时：保留最近 3 个消息单元，其余生成确定性摘要（工具行 300 字符、其他 500 字符、总上限 6000 字符）。
- 随后用同一模型精炼摘要（输出上限 `min(2048, reservedOutputTokens)`）；精炼失败时回退确定性摘要，不影响主任务。
- Provider 返回 413 或上下文长度类错误时触发**紧急压缩**（仅保留最后 1 个单元）；一次后仍超限则抛 `context.exhausted`。
- 压缩摘要、源范围与精炼结果都持久化到会话；`/compact` 手动触发；`/new` 清除摘要。

### 思考等级

统一六档：`default`（默认，不发送参数）、`off`、`minimal`、`low`、`medium`、`high`。

| 等级 | OpenAI（`reasoning_effort`） | Anthropic（thinking 预算） |
| --- | --- | --- |
| `default` | 不发送 | 不发送 |
| `off` | `minimal`（界面显示 `off→minimal`） | `{ type: "disabled" }` |
| `minimal` | `minimal` | 1024 tokens |
| `low` | `low` | `reservedOutputTokens` 的 25% |
| `medium` | `medium` | 50% |
| `high` | `high` | 75% |

Anthropic 预算按 `[1024, reservedOutputTokens − 1]` 截断；启用已知思考要求 `reservedOutputTokens > 1024`。预算计入 `reservedOutputTokens` 内，提高等级会减少同次输出中最终文本与工具调用的可用 token。

### 作用范围

- 只作用于主 Agent 请求；上下文压缩与 Smart Approval 审查保持 Provider 默认。
- 每个 turn 起始的等级快照贯穿该 turn 的工具循环与重试。
- Anthropic 的 `thinking`/`redacted_thinking` 与签名块作为 `providerState` 持久化并在工具调用与恢复后回传；切换 Provider 时忽略不匹配的状态。
- 设置入口：`--thinking <level>`、`CODEN_THINKING_LEVEL`、配置 `thinkingLevel`、REPL `/thinking [level]`。
