会话是可恢复的事件与消息记录，不是进程快照。CodeN 通过 JSONL 持久化系统、用户、assistant、tool 消息以及必要状态；恢复时重建上下文，并把缺失结果的中断工具调用补成显式错误，让模型看到真实的不完整状态。

## 会话

### 会话标识与位置

- 会话 ID 是 UUID，通过 `--resume <session-id>` 引用；格式限制为 `[A-Za-z0-9][A-Za-z0-9._-]{0,127}`。
- 文件位于 `$XDG_DATA_HOME/coden/sessions/<workspace-hash>/`：`<id>.jsonl`（会话记录）与 `<id>.trace.jsonl`（运行事件 trace）。
- 目录 `0700`、文件 `0600`；会话与 trace 可能包含推理内容与敏感输入，不要未经审查地分享。

### 记录内容

| 记录类型 | 数据 |
| --- | --- |
| `session.created` | 工作区与会话 ID |
| `message` | 每条 system/user/assistant/tool 消息 |
| `tool.call.updated` | Hook 更新后的工具输入 |
| `context.compacted` | 压缩摘要与源范围 |
| `session.title` | 显式标题 |
| `session.thinking` | 思考等级（turn 起始快照）|
| `session.reset` | `/new` 重置标记 |

首条非 hook 用户消息自动成为会话标题；`/new` 之后标题重新取首条消息。

### 恢复（resume）

```bash
coden --resume                  # list sessions for the current workspace
coden --resume <session-id>     # resume a specific session
```

- 恢复时重新构建系统消息（最新系统提示、工具目录与 Skill 名称列表），恢复消息历史、压缩摘要与压缩范围、最后保存的思考等级。
- 尾部未完成的工具调用会补齐为 `runtime.interrupted: tool execution did not complete...` 错误并记录警告。
- 恢复的会话文件行损坏时抛出逐行错误；仅当**最后一行**不完整时忽略并警告。
- 恢复时的思考等级解析顺序：显式 `--thinking` > 会话保存值 > 用户/项目配置 > 默认；显式覆盖会写回会话。

### 列表输出

```text
<id>  <title>  (<N> messages, YYYY-MM-DD HH:MM)
```

- 按最后活动时间倒序；无标题的会话显示 `(no title)`；trace 文件不列入。
- 列表输出不含 token 用量或其他账户信息。

## 会话存储

### 存储位置

```text
$XDG_DATA_HOME/coden/sessions/<workspace-hash>/
├── <session-id>.jsonl          # session records
└── <session-id>.trace.jsonl    # runtime event trace
```

- 默认 `~/.local/share/coden`；`XDG_DATA_HOME` 可整体迁移。
- 目录 `0700`、文件 `0600`；会话按工作区哈希隔离（同一路径不同进程共享目录）。
- 会话 ID 由 UUID 生成，格式 `[A-Za-z0-9][A-Za-z0-9._-]{0,127}`。

### JSONL 记录

每行一个记录：

```json
{"version":1,"id":"…","timestamp":"2026-08-31T12:00:00.000Z","type":"message","data":{"role":"user","content":"…"}}
```

记录类型与恢复语义见 [会话](/coden/zh/docs/agent/sessions/)。会话文件中禁止修改的部分包括消息结构校验（`isMessage`）、工具调用更新的唯一性校验（`tool.call.updated` 必须恰好匹配一条 assistant tool_calls）。

### 恢复校验

- 逐行解析；无效的非末行记录抛出错误（行号），只有**最后一行不完整**时忽略并警告。
- 尾部未完成工具调用自动补齐：`runtime.interrupted: tool execution did not complete before the previous process exited`。
- 恢复成功后 `#created` 置位，后续消息继续追加到同一文件。

### 备份与清理

| 操作 | 结论 |
| --- | --- |
| 备份 | 复制 `<id>.jsonl` 与 `<id>.trace.jsonl` 即可；保留原权限（`0600`） |
| 删除 | 删除两个文件即清除会话；不存在其他索引 |
| 迁移 | 修改 `XDG_DATA_HOME` 后所有会话/trace/全局插件跟随新目录 |

### 敏感性

会话文件可能包含模型推理内容、`redacted-thinking`、签名、用户输入与代码片段。不要未经审查地提交、分享或分发；保持本地私有权限。
