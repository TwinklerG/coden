## 会话标识与位置

- 会话 ID 是 UUID，通过 `--resume <session-id>` 引用；格式限制为 `[A-Za-z0-9][A-Za-z0-9._-]{0,127}`。
- 文件位于 `$XDG_DATA_HOME/coden/sessions/<workspace-hash>/`：`<id>.jsonl`（会话记录）与 `<id>.trace.jsonl`（运行事件 trace）。
- 目录 `0700`、文件 `0600`；会话与 trace 可能包含推理内容与敏感输入，不要未经审查地分享。

## 记录内容

| 记录类型 | 数据 |
| --- | --- |
| `session.created` | 工作区与会话 ID |
| `message` | 每条 system/user/assistant/tool 消息 |
| `tool.call.updated` | Hook 更新后的工具输入 |
| `context.compacted` | 压缩摘要与源范围 |
| `session.title` | 显式标题 |
| `session.thinking` | 思考等级（turn 起始快照）|
| `session.reset` | `/new` 重置标记 |

首条非 hook 用户消息自动成为会话标题；`/new` 之后标题重新取首条消息。

## 恢复（resume）

```bash
coden --resume                  # list sessions for the current workspace
coden --resume <session-id>     # resume a specific session
```

- 恢复时重新构建系统消息（最新系统提示、工具目录与 Skill 名称列表），恢复消息历史、压缩摘要与压缩范围、最后保存的思考等级。
- 尾部未完成的工具调用会补齐为 `runtime.interrupted: tool execution did not complete...` 错误并记录警告。
- 恢复的会话文件行损坏时抛出逐行错误；仅当**最后一行**不完整时忽略并警告。
- 恢复时的思考等级解析顺序：显式 `--thinking` > 会话保存值 > 用户/项目配置 > 默认；显式覆盖会写回会话。

## 列表输出

```text
<id>  <title>  (<N> messages, YYYY-MM-DD HH:MM)
```

- 按最后活动时间倒序；无标题的会话显示 `(no title)`；trace 文件不列入。
- 列表输出不含 token 用量或其他账户信息。
