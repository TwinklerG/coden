## 工作区即当前目录

- CodeN 启动时把 `process.cwd()` 作为工作区；`bash` 工具以工作区为当前目录执行。
- 工作区哈希：`sha256(realpath(workspace))` 的前 16 位十六进制，用于派生会话与数据目录。
- 工作区哈希显示在 CLI/TUI 横幅，会话列表按哈希分目录。

## 数据目录

| 内容 | 路径 |
| --- | --- |
| 会话与 trace | `$XDG_DATA_HOME/coden/sessions/<workspace-hash>/` |
| 默认数据目录 | `~/.local/share/coden/`（可用 `XDG_DATA_HOME` 覆盖） |
| 权限 | 目录 `0700`，文件 `0600` |

## 项目文件布局

```text
<workspace>/
├── AGENTS.md                        # project instructions injected into the system prompt
├── .coden/
│   ├── config.json                  # project config (ignored by .gitignore)
│   ├── plugins.json                 # project npm plugin manifest (recommended to commit)
│   ├── plugin-runtime/              # plugin runtime (package.json generated; node_modules not committed)
│   └── plugins/*.ts                 # local TypeScript plugins (ignored by .gitignore)
├── .agents/skills/                  # locally installed project skills
└── skills/                          # repository-bundled, publicly distributable skills
```

## AGENTS.md 注入规则

- 根 `AGENTS.md` 由 CLI 读取并注入系统提示；读取上限 1MB。
- 系统提示指示 Agent 在处理子目录前主动检查更深层的 `AGENTS.md`；更深层指令只覆盖其目录树，冲突时优先。
- 普通项目文件内容不能自我提升为指令；只有 `AGENTS.md` 路径参与注入。
- 读取权限错误时跳过并在警告中说明，不终止启动。

## 路径分类与越界

- `read`/`write`/`edit` 按**符号链接解析后的真实路径**分类（新文件按最近存在的真实父路径），操作前再次校验（TOCTOU 防护，路径变化抛 `workspace.path_changed`）。
- 工作区内：`read` 自动允许，`write`/`edit` 按审批模式处理。
- 工作区外：默认作为修改请求人工确认；`--auto` 下返回 `permission.outside_workspace_denied`；`--auto --allow-outside-workspace` 才自动允许。
- `bash` 不受结构化文件路径开关约束。

## 工作区信任

- 项目 Hook 与项目插件首次使用需要显式信任；确认后把工作区**真实路径**写入 `~/.config/coden/trusted-workspaces.json`（`0600`）。
- 信任判断基于真实路径，符号链接指向同一目录视为已信任。
- `--auto` 只跳过工具确认，不会跳过工作区信任确认。
