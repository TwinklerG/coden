## 配置类环境变量

| 变量 | 取值 | 作用 |
| --- | --- | --- |
| `CODEN_PROVIDER` | `openai` \| `anthropic` | 覆盖 Provider |
| `CODEN_MODEL` | 模型标识符 | 覆盖模型 |
| `CODEN_MAX_STEPS` | 正整数 | 覆盖最大步骤数 |
| `CODEN_THINKING_LEVEL` | `default` \| `off` \| `minimal` \| `low` \| `medium` \| `high` | 覆盖思考等级 |

## 凭据类环境变量

| 变量 | 作用 |
| --- | --- |
| `CODEN_OPENAI_API_KEY` | OpenAI Provider 的 API Key（必需） |
| `CODEN_ANTHROPIC_API_KEY` | Anthropic Provider 的 API Key（必需） |
| `CODEN_OPENAI_BASE_URL` | OpenAI 兼容端点的 Base URL（可选） |

凭据变量由 Provider 构造时直接读取；缺失时启动失败（`..._API_KEY is required`，退出码 2）。

## 路径类环境变量

| 变量 | 作用 | 默认 |
| --- | --- | --- |
| `XDG_CONFIG_HOME` | 配置根目录（`<root>/coden/config.json`、`trusted-workspaces.json`） | `~/.config` |
| `XDG_DATA_HOME` | 数据根目录（`<root>/coden/sessions/`、`<root>/coden/plugins/`） | `~/.local/share` |

## 配置文件 env 字段注入

用户级与项目级配置的 `env` 字段会在配置加载时注入进程环境：

- 两级合并：项目级逐键覆盖用户级。
- **不覆盖** shell 中已导出的同名变量：`CLI > 环境变量 > 配置 env`。
- 只接受字符串值；非字符串值导致配置加载失败。
- 注入在 Provider 创建之前完成，因此 `env` 字段可以承载 API Key。

```json
{
  "env": {
    "CODEN_OPENAI_API_KEY": "sk-...",
    "CODEN_MODEL": "gpt-5-mini"
  }
}
```

## Hook 子进程额外变量

Hook 命令执行时还提供 `CODEN_PROJECT_DIR`、`CODEN_SESSION_ID`、`CODEN_HOOK_EVENT`（见 [I/O 协议](../hooks/protocol)）。
