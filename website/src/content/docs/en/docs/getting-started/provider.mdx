CodeN supports exactly two providers: `openai` (default) and `anthropic`. The provider determines the API endpoint, authentication, and thinking-parameter mapping; the default model is `gpt-5-mini`.

## OpenAI (default provider)

```bash
export CODEN_OPENAI_API_KEY=sk-...
coden "say hello"
```

Custom compatible endpoint (proxy or compatible service):

```bash
export CODEN_OPENAI_API_KEY=sk-...
export CODEN_OPENAI_BASE_URL=https://api.example.com/v1
coden --model your-model-id "say hello"
```

## Anthropic

```bash
export CODEN_ANTHROPIC_API_KEY=sk-ant-...
coden --provider anthropic --model claude-sonnet-4-20250514 "say hello"
```

Switching providers requires an explicit `--provider anthropic`. The provider accepts only `openai` or `anthropic`; any other value fails argument parsing.

## Credential sources and precedence

CodeN reads **process environment variables** when constructing the provider. Sources, highest first:

1. Environment variables already exported in the shell before starting CodeN.
2. The config `env` field: injected into the process environment at config load time, but it does **not** overwrite an already-exported shell variable of the same name.
3. With no key set, startup fails with exit code 2 and an error shaped like `CODEN_OPENAI_API_KEY is required`.

Config `env` example (user scope, `~/.config/coden/config.json`):

```json
{
  "env": {
    "CODEN_OPENAI_API_KEY": "sk-..."
  }
}
```

A project-level `<workspace>/.coden/config.json` accepts the same `env` field; when both scopes are merged, project-level keys override user-level keys one by one.

## Secret placement boundaries

- Never put a key in a directory that gets committed, shared, or distributed. Supported locations are `~/.config/coden/`, `.coden/` (excluded by `.gitignore`), and the config `env` field.
- CodeN does not read `.env` files automatically; `set dotenv-load` in `just` affects only `just` subprocesses during development.
- Session JSONL and trace files may contain model reasoning and user input; do not share them without review.

## Verify a minimal configuration

```bash
coden -p "Reply with exactly: coden-ok"
```

Print mode emits plain text and exits after a single turn, which makes it a good authentication and endpoint check. The expected output contains `coden-ok`.
