## Launch

```bash
coden                 # interactive REPL
coden "your task"     # run one task and exit
coden --cli "your task"
```

With no interface flag, CodeN always enters CLI/REPL regardless of terminal type. The startup banner shows version, workspace hash, model, approval mode, thinking level, and the current session ID.

## Input

| Input | Behavior |
| --- | --- |
| plain text | submitted as a task |
| single trailing `\` | inserts a newline to continue input (fallback stream; with the multiline editor Enter submits directly) |
| `Ctrl+C` | cancels the current task (aborts the request and tools), does not exit |
| `Ctrl+D` (empty input) | exits |
| lines starting with `/` | handled by [Slash Commands](./slash-commands) |

## Output

- Model answers and tool activity render as a continuous stream: tool start/completion with duration, provider retries, thought duration, token summaries.
- `--verbose` shows more runtime detail (including skill discovery failure reasons).
- Authorization requests print inline: risk level, tool name, input preview, `[y]es / [s]ession / [N]o` (dangerous operations offer only `[y]es / [N]o`).
- `NO_COLOR` disables color; terminal width is used to align authorization prompts.

## Task lifecycle

- With a prompt: one turn runs and the process exits; exit code `0` means successful completion.
- Without a prompt: the REPL loop runs until `/quit`, `Ctrl+D`, or failure.
- Session end (`completed`/`failed`/`cancelled`/`eof`/`quit`) triggers the `SessionEnd` hook and trace flush.
